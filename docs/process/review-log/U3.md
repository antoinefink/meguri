## Open after round 3

- P2 (advisory, non-blocking): driver self-test failure tracebacks leave the quarantine unsanitized. `oracle/driver/tests/__main__.py:47-49` copies the full unittest traceback text into the TAP output, and the runner's own `traceback.print_exc()` (`__main__.py:62`) does the same for a broken runner. That text can hold driver source lines and Anki frames or messages. `tools/mg oracle test` saves the output under `build/mg/`, outside the quarantine, against `oracle/AGENTS.md:7`. Suggested fix: send both paths through `errors.log_exception` (class plus driver `file:line` only). Not fixed at integration.
- P2 (advisory, non-blocking): scenarios with the same stem overwrite each other's golden. Discovery strips the suffix (`oracle/driver/harness.py:131-132`), so `smoke/foo.yaml` and `smoke/foo.json` both map to `goldens/smoke/foo.json`; `cmd_record` (`harness.py:272-277`) writes the second over the first and reports both recorded. Compare then fails for one of them, and a bump can falsely report a full record. Suggested fix: in discovery (`_select`), reject duplicate `item.rel` values with an error before any golden is written, with a self-test. Not fixed at integration.
