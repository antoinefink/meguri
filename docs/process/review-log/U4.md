## Open after round 3

- P2 (advisory, non-blocking): observation ref lists silently accept empty entries. `core/crates/meguri-testkit/src/scenario/model.rs:771-775` drops empty strings after `split(',')`, so a malformed request such as `card(#c1,,#c2)` or `card(#c1,)` is accepted, although `scenario.schema.json` forbids it. A probe showed the malformed scenario reported as `missing` and T0 exiting 0; D10 requires the always-failing `invalid` status. Fix: return a `FormatError` for any empty comma-separated entry, keep a wholly empty `()` as `ObservationArgs::None`, and add a T0 regression test for both cases. Not fixed at integration.
