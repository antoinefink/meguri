## Round 1 (fixed in 4c1e2c9)

- Session records went to the invoking checkout's ledger uncommitted, which left the main checkout dirty and kept R1958 records out of version control. `worktree new` now commits the record as the branch's first commit; `session record` commits on the current branch, touching only the ledger. A record that cannot be written or committed is an error, and a new worktree is removed.
- `worktree new` did not install the commit-msg hook for every role. Roles were matched as substrings, so "implementer fixer" skipped the sparse checkout, the deny profile and the Spec check. Spec: now also accepts requirement ids for UI work no spec covers.
- The deny profile left github.com content hosts, oracle/ in the main checkout, refs/, installed Anki add-ons and Migaku URLs open. It now covers them, plus a PreToolUse hook that blocks Anki, AnkiDroid, AnkiConnect and Migaku URLs on any host.
- Similarity: the corpus was not pinned and a partial corpus passed (now 54 tags, partial is an error). Names with non-ASCII, tab or newline characters were not scanned (NUL-separated now). `--rev` copied oracle/ into build/. Concurrent scans deleted each other's index builds (per-build mkdtemp and a flock now).

## Round 2 (fixed in 737af04)

- Bash deny rules only matched with the subcommand right after `git`, `docker run` or `docker compose`, so `docker compose -f docker/compose.yml ...` and `git -C <dir> show` passed. Rules now start with a wildcard and put one before each subcommand; direct docker run/exec/cp/build/save/export/debug/container and docker-compose are denied, and Bash rules cover the reports and indexes that only Read rules covered.
- The profile was rendered with sed, which reads `&` and `\` in a path as replacement syntax. jq now inserts paths literally; an unknown placeholder fails.
- Parallel `session record` runs collided on index.lock and could leave a record uncommitted. A mkdir lock in the common git dir serializes append and commit.
- Words in a multi-line string literal all got its first line, so allowlist line ranges exempted the lines below (INDEX_VERSION 2).
- Explicit scan paths were used as given: `./oracle/x.py` escaped the oracle/ exclusion. Paths are now normalized and paths outside the checkout refused.

## Round 3 (fixed in 491f9f0)

- The deny profile only matched literal `pip download anki` / `pip install anki` prefixes, so `python3 -m pip download anki`, `pip install --upgrade anki`, `env X=1 pip install anki` and `/usr/bin/pip3 install anki` passed. Rules now cover pip download/install/wheel of anki in any form and any `python -m pip` command naming anki.

## Round 4 (fixed in 6008afb)

- `pip install aqt[qt6]` (pulls the anki wheel), the case variants `Anki` and `ANKI`, and `uv add`, `uv tool`, `uvx` and `pipx run` installs of anki or aqt all passed. Each is now denied, with matcher tests.

## Round 5 (fixed in 8b3f622)

## Open after round 6

- P1 (blocking): the implementer profile does not deny `uv run --with anki`. `.claude/settings.implementer.json:81-87`: `uv run --with anki python -c 'import inspect, anki; print(inspect.getsource(anki))'` matches no deny rule, so an implementer can install the real Anki wheel and read its source. Fix: add deny rules for `uv run --with anki` and `uv run --with aqt`, including variants such as `--with=anki`, and add matcher tests for them in `tools/tests/provenance.bats`. Not fixed at integration.
- P2 (advisory, non-blocking): the corpus cache key ignores directory-source file contents. `tools/similarity/meguri_similarity/corpus.py:140-142`: for a non-git add-on source the key uses only file size and integer-second mtime, so a same-size edit within the same second, or an update that keeps timestamps, reuses stale fingerprints in `open_or_build()`. Fix: include content digests in the key. Not fixed at integration.
- P2 (advisory, non-blocking): nightly JPlag passes when no reference tags exist. `tools/similarity/meguri_similarity/jplag.py:67-69`: with refs/anki cloned `--no-tags`, every language comparison is skipped and the summary is still `pass`. Fix: return an error when no reference tags are available, and report requested tags that are missing. Not fixed at integration.
- P2 (advisory, non-blocking): allowlist removal merges separate match runs. `tools/similarity/meguri_similarity/scan.py:118-121`: removing allowlisted fingerprints from the array joins runs that were separate in the file, so two 3-match runs become one 6-match run and can cross the structural threshold; adding an allowlist entry can make a passing file fail. Fix: keep the original positions, or insert run breaks at the removed entries, before `longest_true_run()`. Not fixed at integration.
- P2 (advisory, non-blocking): hook install uses a shared temp file and races. `tools/mg.d/hooks.sh:40`: `tmp="$target.tmp"` is the same for every invocation, so parallel `hooks install` runs (for example from parallel `worktree new`) clobber each other's temp file and fail with spurious hook-write errors (Codex reproduced it). Fix: `mktemp` in `$dir`, then `mv` over the hook. Not fixed at integration.
