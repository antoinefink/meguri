## Round 2 (fixer s-20261016T072456Z-78bbd279)

Two P1 findings.

- Finding 1, fixed in c187473: d6e8acf's entropy exemption still dropped 4-7 character runs next to compressed data (zip entry names, PNG text chunks, EXIF), and runs under 4 characters were never scanned, though deck, tag and media names have no minimum length (R1940). Every printable run of a binary file now counts, at any length, matched against the whole token set. Only ranges that a parsed format defines as compressed data, fixed fields or tables are exempt (PNG with CRC-checked chunks, JPEG, zip, zstd), and there a token of 8 bytes or more still counts. A structure that does not check out ends the exemption. 0x1f joins a run as a separator, so a nested deck name matches its token. New tests cover each format and short names and metadata in staged binary files.
- Finding 2, not fixable in the fixer's worktree: V3 needs an oracle with spec/U15's `check --schedule`, which the main checkout lacked. Closed by the integrator's run below.
