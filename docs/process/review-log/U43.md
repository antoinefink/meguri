## Implementation and provenance

The conformance adapter shares the pure queue but does not prove production behavior. Before Accepted, the service queues a captured journal intent. The file worker makes it durable within one second. Recovery checks the collection file, recorded revlog assignment, full rows and scheduling context; it follows earlier accepted events in order and uses the captured time before day maintenance. The UI answer call performs no file sync.

CoreHost and Runtime share one engine, queue provider and review service. The typed FFI preserves C1–C19 results and ordered events. Swift maps generated types into its public DTOs and uses the interactive lane for short calls and the control lane for lifecycle drains. U37 still owns public Swift opening; closed-call tests are not live-session proof. A Rust composition test opens the actual shared provider and checks review, persistence, events, close and reopen.
