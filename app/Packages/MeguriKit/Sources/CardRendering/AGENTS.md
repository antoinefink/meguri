# CardRendering

- `CardWebConfiguration.shared` is production's store/controller/handler. Never install pair scripts in that controller; execute them only in the pair's host world. The pair belongs to the session, and its owner calls `close()`.
- Pass the bound root and U31 tracked-name/case-key snapshot to `MediaPathResolver.open`. Supply arrival updates; never list the folder for each request. Close the previous binding before a root switch. AV filenames are raw; URL paths decode once.
- `present` reorders before any web call, in the enclosing CA transaction. Use `onCommitted` for dependent work; setting another CA completion block replaces WebKit presentation. Frame probes call the returned token's recorder independently; double rAF never supplies physical frame evidence.
- `prepare`'s returned identity is readiness; a runtime `settled` receipt can precede a concurrent appearance change's paint barrier.
- Audio policy is caller-resolved from the home deck. Automatic transitions replace waiting entries and may retain only the current clip, including its paused state. Manual replay always replaces everything. U69 supplies non-native codecs.
