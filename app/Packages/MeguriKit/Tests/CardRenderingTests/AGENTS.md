# CardRenderingTests

- The Xcode Unit plan runs these in the VM. Swift package tests run on the host in a borderless window at (-30000, -30000) that is never ordered in. Native audio playback requires confirmed real hardware: the VM has no audio route, and loading audio there can block the next video test. Skip audio before creating its page; keep video enabled. WebKit runs no `requestAnimationFrame` in these off-screen windows, and no frame is presented: anything that needs frames, the swap's frame, the keyboard or a relaunch goes into the app (`MeguriUITests/CardSwapTimingSpikeTests`, `TestHooks/SpikeRoutes.swift`) and runs through `tools/mg perf-ui` in the test VM.
- Suites that share WebKit and this process's memory nest in `RenderingSpikes` (`.serialized`, 2-minute limit): `swift test` runs every other test target in the same process, in parallel.
- Media is made at run time (`Spikes/Support/SpikeAssets.swift`: silent MP3, noise PNG, H.264 MP4, system faces rebuilt from their tables). Commit no binary fixture, and never play audible sound on the host.
- Memory checks count the pages' web content processes too (`spikeWebContentFootprint`: pid through WebKit's `_webProcessIdentifier`, SPI, read only in tests and test hooks). S1(f) failed R1853 for them (decision record s1, escalated): their check is a `withKnownIssue` until the plan decides. Old-card retention is checked with a `FinalizationRegistry` in the page, not with footprints. A footprint includes uncollected JavaScriptCore garbage: request explicit GC through the test-only pool SPI only after all memory readings, then drain bounded event-loop turns before reading finalization counts; allocation pressure does not guarantee collection.
- `WKWebsiteDataStore(forIdentifier:)` writes under `~/Library/WebKit/`: use a fresh identifier per test and remove it afterwards, also on failure.
- `Spikes/Support/` is U65's throwaway harness (`SpikeMediaHandler`, `SpikePagePair`). When U67's `MediaSchemeHandler` and `CardPagePair` land, point the spike tests at them and delete the support (decision records `docs/design/decisions/s1-*.md`, `s2-*.md`).
