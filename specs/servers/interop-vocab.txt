# Interface names the servers specs use that are not ordinary words: the
# AnkiConnect action names, parameters and result keys, the Migaku routes,
# payload keys, form fields and syntax tags, the HTTP, CORS and WebSocket
# header names, the integrations config members, the status, error and
# event names of the host and its FFI, the transcript keys and steps, and
# the media types and file signatures the Migaku pipeline reads.
# Ordinary words stay unmasked even where they are keys, values, header
# names or action names: Host, Origin, Connection, Expect, Upgrade, Allow,
# Vary, Date, Server, Accept, Location, chunked, identity, websocket,
# action, version, params, key, result, error, permission, granted, denied,
# scopes, actions, multi, sync, suspend, suspended, query, note, notes,
# card, cards, deck, decks, fields, tags, options, audio, video, picture,
# data, path, url, filename, order, ascending, descending, question,
# answer, css, type, queue, due, interval, factor, reps, lapses, left,
# flags, profile, value, state, receive, create, sentence, translation,
# definitions, images, title, input, src, alt, reading, success, created,
# fallback, pending, baseline, conflict, renamed, skipped, Front, Back, Name.
# Content types written with a slash (application/json, audio/mp4, ...)
# are not listed: the scan masks identifiers, which never hold a slash;
# their subtypes are listed where they are not ordinary words.
# Merged from the wave-2 package lists (build/wave2-vocab, 2026-11-10).
