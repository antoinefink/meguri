# meguri-package

- `reader::verify` checks the P11 writer layout. General P12 inspection must allow unknown members, absent media and no placeholder.
- `inspection_zip` scans all raw central records before constructing a three-entry virtual ZIP suffix. Keep unknown names/extras out of zip's index; preserve byte-exact duplicate detection and both classic/optional-Zip64 bounds.
- Inspection tokens own unpublished U32 staging. Only storage inspects collection rows; replacement consumers own R7 stamps and activation.

- ForcedBackupProvider runs on its caller’s worker, with the passed Working collection for imports. Keep its Maintenance lease and serialization lane through strict sidecar recording; release before replace. RF2 never deletes a published backup.

- RF2 entry tokens consume once, bind committed `Collection::last_seq` plus engine/generation, and retain their private package copy. Never expose candidate paths at FFI. Combined copy preflight reuses inspection preparation.

- E7/P15 is opt-in (`file_export`); P11 backups/server copies and general `UnsupportedMedia` intake stay collection-only. Export source validation must run after the final artifact hash at delivery, not just inside AtomicFile's verifier. It owns read-only descriptors, never engine/media locks or capture staging.

- E7 inventory classifies with descriptor-relative no-follow stat before any media read. M8's optional colon applies only to `thumbs?db`. Build protected identities once per pass from admitted paths and direct U32 staging entries; recheck their bindings after inventory. Unit-only open injection proves permission refusals under root; it is not native permission evidence.
